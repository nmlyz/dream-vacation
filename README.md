A tiny program that writes one emoji for a dream vacation to a file. The pick is Mount Fuji: a single named place, not a generic holiday symbol.

## Run it

```sh
python3 main.py
```

It writes the emoji to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Standard library only, no network, deterministic: two runs produce byte-identical output.

## The pick

> 🗻

Thirty-six candidate emoji were written from deliberately different angles — named places, skies, animals, journeys — the generic holiday symbols were thrown out, and the survivors were judged pairwise against the brief by three readers: a travel editor weighing how vivid the postcard is at a glance, a stranger weighing whether it makes them want to book the flight, and a purist weighing whether it points at one particular dream rather than any holiday. Mount Fuji won the final 2-1 over the Milky Way: a postcard of a place with a flight to book, where the Milky Way names a sky, not a destination.
